01 / System flow

One request, five honest layers.

The browser never talks directly to MongoDB or the model files. FastAPI coordinates everything through repositories and a manifest-gated ML loader.

02 / Backend

An API that reports its real state.

No provider is simulated. Unconfigured integrations are reported as disabled through /api/v1/system/config.

03 / Persistence

MongoDB is the memory of the system.

The free Atlas M0 cluster holds 30 collections. Repositories keep database code out of routes.

usersAccounts, roles, password hashes and account status.
fraud_analysesRisk band, component scores, evidence and source coverage.
support_messagesChat question + answer with random session ID and 30-day TTL.
audit_logsActor, action and timestamp for review and traceability.
MongoDB does not run the ML model and does not store card, PAN, CVV or KYC data. It remembers application state after the browser closes.

REJECTED

Contextual signals were unavailable during training. Anomaly scoring uses labelled rule fallbacks.

Honesty rule: LinearSVC confidence is a sigmoid-mapped decision margin, not a calibrated fraud probability. High ranking performance does not mean low false-positive risk.
